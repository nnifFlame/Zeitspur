# Zeitspur für Android

Dieses Repository dient ausschließlich der Verteilung fertiger APK-Dateien und Updates. Der App-Quellcode ist nicht öffentlich.

## Installation

[Neueste APK herunterladen](https://github.com/nnifFlame/Zeitspur/releases/latest/download/Zeitspur.apk)

APK auf dem Android-Gerät öffnen und die Installation bestätigen. Voraussetzung: Android 9 oder neuer.

## Funktionen

Kategorien, sekundengenaue Zeitaufzeichnungen, Notizen, Analysen nach Tag/Woche/Monat/Jahr sowie lokale Datensicherungen.

## Updates

Die App prüft beim Start die öffentlichen Releases dieses Repositorys. Ein Update wird nach Zustimmung heruntergeladen und mit Androids Installationsdialog installiert. Dabei bleiben die bestehenden App-Daten erhalten.

## Datenschutz

Zeitaufzeichnungen und Notizen bleiben auf dem Gerät. Nur die Update-Prüfung kontaktiert GitHub.

## Hinweis zu GitHub-Archiven

Die von GitHub automatisch angezeigten Links „Source code (zip/tar.gz)“ enthalten hier ausschließlich diese Downloadhinweise, keinen App-Quellcode.
